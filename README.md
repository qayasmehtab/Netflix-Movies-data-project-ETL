## 🔄 Data Pipeline Explanation

### 📦 Data Source (ZIP File)
- Raw dataset provided in compressed format  
- File: `netflix_titles.zip`  
- Ensures efficient storage and transfer  

---

### ⚙️ Data Extraction (Python)
**Script:** `extract_zip.py`  
- Extracts CSV files from ZIP archive  
- Organizes data into structured directories  

📁 Output Directory:  


---

### 🧹 Data Cleaning & Transformation (Pandas)
**Script:** `clean_data.py`  
- Handles missing and inconsistent values  
- Normalizes text and date formats  
- Prepares data for database ingestion  

📁 Output Directory:  


---

### 🗄️ Load to SQL Server
**Script:** `load_to_sql.py`  
- Loads processed data into SQL Server  
- Creates relational tables  
- Maintains data accuracy and integrity  

---

### 📊 Data Analysis & Visualization
**Tools:** SQL, Jupyter Notebook, Plotly  
- SQL queries for analytical insights  
- Interactive visual dashboards  
- Trend analysis and content distribution insights
